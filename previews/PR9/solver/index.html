The solver

Converting between primitive and conserved variables, using entropy and rapidity as the iteration variables. Above them, a projection onto the valid range that never fails, and a replaceable physics policy on top of it.

EntropyEOS.Con2PrimStage — Type
Con2PrimStage

What con2prim_start hands to con2prim_finish: an iterate as the (s, w) and the warm start u it was evaluated with, which reproduce it bit for bit, rather than the iterate itself, which is several times larger. It is the last Newton iterate if the Newton converged, and the best one otherwise.

EntropyEOS.Residuals — Type
Residuals

One evaluation of the residual pair and its analytic Jacobian, plus the intermediate quantities the caller reuses.

The two residuals are the momentum residual f₁ = sinh(w) - cosh(w)·V, deliberately not squared so the S → 0 root stays simple rather than double, and the normalized energy residual f₂ = (τ_model - τ)/max(τ, τ_floor_rel·D). sr_ext is the extended entropy window at ρ, which the Newton clamps its step to.

EntropyEOS.bracket_scan — Method
bracket_scan(eos, D, τ, yₑ, S_par, S_perp, B², w_max, τ_floor_rel, n_scan, s_in, w_in,
             w_seed0, u_seed0, max_iter_1d, tol; nmax = Val(BRACKET_SCAN_MAX))

Find a sign-changing interval in s for the outer solve.

Endpoint signs are not enough: the outer function is non-monotone near the extension seams, and the extended entropy bracket can span ten decades. So the search is a multi-point scan, half of it uniform across the physical range and half a geometric ladder of relative offsets around s_in.

The split matters and was measured. The global half finds a single monotone root whatever s_in is, which is what a crude cold seed needs. The local half concentrates resolution near a good s_in, which is what a Newton that stalled near the root needs – and "near" there is a relative statement, so a ladder sized to the local entropy span would be orders of magnitude too coarse.

Every candidate gets a full-precision inner solve. A loosened scan-only tolerance was tried in the C++ and reverted: near a genuine near-degenerate root an under-converged inner solve can flip the sign of the outer residual and manufacture a false bracket that masks the real one.

nmax sizes the stack scratch. It is a Val so a GPU caller can shrink the per-thread local memory without touching the algorithm.

EntropyEOS.cold_seed — Method
cold_seed(eos, D, τ, yₑ, S_par, S_perp, B², w_max, n_pass, n_s_iter)

Manufacture a starting point with no prior iterate.

Every step is an exact relation and the only lagged quantity is the pressure, which starts at zero: energy gives the enthalpy density, momentum gives the rapidity, the energy identity gives the internal energy, and the guaranteed monotone entropy solve gives the entropy. Being field-aware is what makes this work on magnetized states, where a hydrodynamic seed is badly wrong.

EntropyEOS.con2prim — Method
con2prim(eos, in, opts; s_guess = NaN, w_guess = NaN, u_guess = NaN)

Recover primitive variables from conserved ones.

A damped 2×2 Newton on (s, w) with the analytic Jacobian, backed by a nested one-dimensional fallback that is globally convergent by construction. Supplying guesses from a previous step – the usual case in a hydro evolution – skips the cold-start machinery entirely and typically converges in one or two Newton steps.

"Damped" means clamped, not backtracked. Backtracking was tried and measured harmful: near a locally ill-conditioned Jacobian a halved step barely moves and the iteration stalls, whereas the full clamped step crosses the bad region and recovers quadratic convergence beyond it. Taking the full step unconditionally is what raises the warm-start Newton success rate from 86% to 99%, and the fallback is the safety net for the remainder.

A failure still returns a fully populated best-effort state.

This is con2prim_start followed, where needed, by con2prim_finish, and gives the same result bit for bit. On a GPU the two stages can run as separate kernels.

EntropyEOS.con2prim_start — Method
con2prim_start(eos, in, opts, s_guess = NaN, w_guess = NaN, u_guess = NaN) -> (out, stage)

The first stage of con2prim: the cold seed, if a guess is missing, and the Newton. If is_done(stage), out is con2prim's result; otherwise out is a placeholder of NaNs, and con2prim_finish on stage gives the result.

On a GPU a warp runs as long as its slowest state, and the fallback costs many times a Newton solve, so a few states in it hold up most warps. Running the first stage over all states and the second over only those not done, as two kernels, keeps them apart:

out[i], st[i] = con2prim_start(eos, cin[i], opts)               # kernel 1, every i
idx = findall(!is_done, st)                                      # compaction, on the device
out[idx[j]] = con2prim_finish(eos, cin[idx[j]], opts, st[idx[j]])  # kernel 2, every j

EntropyEOS.f1_converged — Method
f1_converged(r, tol)

Has the momentum residual converged?

tol bounds the normalized residual tanh(w) - V, not f₁ itself. That matters: f₁ carries a factor of cosh(w), so near the rapidity cap its own double-precision floor sits well above any absolute tolerance, and a test written against f₁ directly could never be satisfied there.

Written as |f₁| ≤ tol·cosh(w) rather than dividing, so the hot path does one multiply; cosh(w) ≥ 1 always, so this is never the tighter test.

EntropyEOS.seed_z_solve — Method
seed_z_solve(D, E, p, S_perp, B², n_iter)

Solve the energy relation for the total enthalpy density, given a lagged pressure. Touches no EOS at all – pure arithmetic.

With q = z + B² the energy relation and the perpendicular momentum projection close on each other without reference to rapidity, giving the cubic H(q) = q - A + B²S_⊥²/(2q²) = 0 with A = E + p + B²/2. H has a single minimum at ∛(B²S_⊥²) and increases above it, and the physical root always lies on that increasing branch, so both bracket ends are exact physical bounds rather than tuned constants. With no field this degenerates to q = E + p, the exact hydrodynamic result, recovered rather than special-cased.

EntropyEOS.edge_root — Method
edge_root(eos, D, τ, yₑ, S_par, S_perp, B², upper, shift, ra, rb, opts) -> Residuals

The root of φ along an entropy edge between ra.w and rb.w, where φ(ra) ≤ 0 ≤ φ(rb): the state on the edge that keeps D and S.

Illinois rather than Newton, because residuals' Jacobian is taken at fixed s and the edge's s moves with w. Where φ has several roots in the bracket, which happens where a table has cs² ≥ 1, this returns whichever it reaches. Returns the iterate with the smallest |φ|; every iterate lies on the edge.

EntropyEOS.face_solve — Method
face_solve(eos, ρ, w_fixed, free_w, w_cap, yₑ, τ, S_par, S_perp, B², u, opts) -> FaceState

The faces that fix ρ. With free_w, the ρmax face: S and τ kept, D lowered, a nested one-dimensional solve, outer in s over the window at ρ, inner in w by pure arithmetic, since h is fixed at fixed (ρ, s). If the rapidity this needs exceeds `wcap, the w_cap face is active too, and the state is re-solved at(ρ, wcap)withτkept andSlowered, addingWCEILED. Withoutfreew`, the wcap and ρmin faces: `w = wfixed,τkept,S` freed.

EntropyEOS.s_solve_at_fixed_ρ — Method
s_solve_at_fixed_ρ(eos, ρ, w_fixed, free_w, yₑ, τ, S_par, S_perp, B², u, opts) -> FaceState

EntropyEOS.w_from_momentum — Method
w_from_momentum(a, S_par, S_perp, B²)

The rapidity at which a state with ρh = a carries the momentum (S_par, S_perp). Pure arithmetic.

With y = sinh² w the momentum relation is y/(1+y) = (σ_par/(1+y))² + (σ_perp/(1+y+b))², with σ = S/a and b = B²/a. The difference of the two sides is increasing and concave in y, so the root is unique, and Newton from either side lands at or below it and then climbs to it monotonically. The bracket [0, y_hydro], with y_hydro the hydrodynamic root with all of S counted (the field only lowers the right-hand side), guards the rounding. Working in y rather than W² keeps the digits of a slow flow, and in ratios keeps Float32 from overflowing.

EntropyEOS.PolicyOptions — Type
PolicyOptions

The reference physics of apply_policy: when a state goes to the atmosphere, and what the atmosphere is.

  • s_atm: the atmosphere's entropy, clamped into the window at ρ_min. NaN means the window's minimum, the coldest atmosphere.
  • ye_atm: the atmosphere's Yₑ. NaN means the incoming state's, clamped.
  • atm_trigger: a state with D < atm_trigger·ρ_min goes to the atmosphere. A non-positive or non-finite value means 1.
  • collapse_to_atmosphere: a state on the ρ_max face goes to the atmosphere.

The sentinels must stay NaN rather than become Union{Nothing,T}, which would destroy isbits-ness and so the GPU path.

EntropyEOS.ProjectionOptions — Type
ProjectionOptions

The valid range that con2prim_safe projects onto: ρ ∈ [ρ_min, ρ_max] and w ≤ w_cap, with Yₑ in the table's range and s in the physical window at (ρ, Yₑ). Densities are κ-rescaled g/cm³, not raw table densities – a common source of error.

EntropyEOS.apply_policy — Method
apply_policy(eos, in, out, proj, pol) -> Con2PrimSafeOut

The reference physics on top of con2prim_safe, called on its output:

out = con2prim_safe(eos, in, opts, proj)       # level 1: projection
out = apply_policy(eos, in, out, proj, pol)    # level 2: physics

Replaces the state by the atmosphere – at rest, at ρ_min, with pol.s_atm and pol.ye_atm – where 1.x would have: on ρ_FLOORED, for D < atm_trigger·ρ_min, on NONFINITE and NOT_CONVERGED, and on ρ_CEILED when collapse_to_atmosphere is set. It then adds FLAG_POL_ATMOSPHERE to level 1's bits, which say why. Otherwise it returns out unchanged.

An application with its own rules replaces this function rather than configuring it. It has in and out to compare, so needs no further flags.

EntropyEOS.check_con_state — Method
check_con_state(eos, in, proj; check_endpoints = false, solver = Con2PrimOptions())

Diagnose a conserved state without repairing it. Every flag it reports is one that con2prim_safe sets; it does not promise to report every face.

By default this is pure arithmetic – no EOS evaluation at all – so it is cheap enough to run at every point of every timestep. It reports a non-finite input, D < ρ_min (ρ_FLOORED), D > ρ_max·cosh(w_cap) (ρ_CEILED), and Yₑ outside the table. With check_endpoints it also runs the entropy-edge part of con2prim_safe's diagnosis, and reports S_FLOORED or S_CEILED where that alone decides the projection, and only when no ρ face is reported. It tests the edges moved outward by the face slack, and the energy residual against check_f2_tol (the solver's tolerance at Float64, 128 times it at Float32), so that a state con2prim_safe accepts as lying on a face is not reported.

EntropyEOS.con2prim_safe — Method
con2prim_safe(eos, in, opts, proj, s_guess = NaN, w_guess = NaN, u_guess = NaN)

Recover primitives from conserved variables, for any input whatsoever, and project them onto the valid range proj describes.

Returns the recovered state together with the conserved variables that correspond to it; the caller adopts cons as its new conserved state. Each face of the valid range that was active sets its own bit in policy_flags, and the returned state lies on it. Each face fixes one primitive and frees one conservative; everything else is kept, to the solver's tolerance:

faceflagwhat gives way
s_maxS_CEILEDτ lowered
s_minS_FLOOREDτ raised
w_capW_CEILEDS lowered
ρ_maxρ_CEILEDD lowered
ρ_minρ_FLOOREDS lowered to w = acosh(D′/ρ_min), D raised to D′ = max(D, ρ_min)
Yₑ boundsYE_FLOORED, YE_CEILEDD_Y set to Yₑ·D with Yₑ clamped

policy_flags == 0 means the input was already valid, and then cons is the input bit-identically. Two outcomes are not projections: NONFINITE (a non-finite input, D ≤ 0 or B² < 0) and NOT_CONVERGED (the solve failed, but the diagnosis finds a valid state inside the range). Both return a fixed valid state only so that a kernel never propagates NaN; apply_policy is expected to replace it.

This level has no notion of an atmosphere or of collapse; that is apply_policy's.

This is con2prim_safe_start followed, where needed, by con2prim_safe_finish, and gives the same result bit for bit. On a GPU the two stages can run as separate kernels.

EntropyEOS.inside_window — Method
inside_window(eos, ρ, s, yₑ) -> Bool

Whether s and Yₑ lie inside their faces of the valid range at density ρ, to the slack with which con2prim_safe tests them: Yₑ within one ulp of the table's range, and s within srange(eos, ρ, yₑ) widened on each side by face_slack of its width (10⁻⁷ at Float64). ρ is not tested against a range. A non-finite argument or ρ ≤ 0 gives false.

This is the validity test for states an application makes itself, for example by reconstruction. Every state that con2prim_safe or project_prim_state returns passes it, including one within the slack of an s face, which con2prim_safe returns unflagged; testing the window exactly would reject that state. The EOS can be evaluated throughout the band, which lies far inside srange_extended.

EntropyEOS.project_prim_state — Method
project_prim_state(eos, ps, proj) -> (state, flags)

The projection on primitives, where every face is a plain clamp: ρ, then Yₑ, then s in the window at the clamped (ρ, Yₑ), then w. Each face is tested with the same slack as in con2prim_safe, so an output of con2prim_safe checks clean; the Yₑ and s faces are inside_window's. Idempotent, bit for bit.

A non-finite state, ρ ≤ 0 or w < 0 has no closest valid state, and gives FLAG_POL_NONFINITE with the fixed state. w is a magnitude, so w ≥ 0 is not a face.
